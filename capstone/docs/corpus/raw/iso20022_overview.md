# ISO 20022 overview

## Public summary

ISO 20022 is a global standard for financial messaging. It provides a common, structured way to
exchange payment and settlement information across banks, payment service providers, corporations,
and regulators.

## Why it matters

The standard improves data quality by using a consistent message structure instead of fragmented,
proprietary formats. This helps institutions exchange richer details such as reference information,
remittance data, party identification, and payment status updates in a more standard way.

## Common concepts

- Payment initiation: a customer or business asks a bank to send funds.
- Message standards: each payment message has a standard structure and defined fields.
- Remittance information: structured details that explain why a payment was sent.
- Status reporting: participants can track whether a payment is pending, processed, rejected, or
  settled.

## Example use in payments

A single payment message can include structured information about the originator, beneficiary,
amount, currency, purpose, and payment references. This makes reconciliation and automation easier
for banks and corporates.

## Practical RAG relevance

For a payments assistant, ISO 20022 material is useful for explaining message flows, common fields,
and how payment information is exchanged between systems. It is especially relevant when answering
questions about remittance advice, payment status, and interoperability between financial systems.
