# NPCI UPI overview

## Public summary

The Unified Payments Interface, UPI, is an instant, real-time payment system developed by NPCI, the National
Payments Corporation of India, an RBI-regulated entity. It is designed to enable inter-bank transactions
through mobile phones. Money moves directly from one bank account to another, so no wallet top-up is needed.
Payments work around the clock, including Sundays and bank holidays.

## How people use it

- A user can send money to a UPI ID, a mobile number or a QR code without first adding the beneficiary or
  waiting for approval.
- Several bank accounts can be linked in one UPI app, such as BHIM, PhonePe or Google Pay.
- UPI is used for bill payments, mobile recharges, loan instalments, insurance premiums and subscriptions.
- An AutoPay feature supports recurring payments within limits that the user sets.

## Authentication

UPI follows the RBI's two-factor authentication rule: the first factor is the mobile number linked to the
user's bank account, and the second is the UPI PIN.

## Interoperability

A UPI ID created on one app can send money to an ID registered on a different app, so payments work across the
major banks and apps in India.
